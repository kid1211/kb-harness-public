# Kitchen sink: colours and emoji

Every colour and emoji the harness may use on a dark page, in one place for the user to review. Open it in VS Code's Markdown preview. Most of it is drawn in the colours of the theme that is open now.

This page is not a rule. When the user marks what is good, the good parts move into `README.md` and the skills.

**How to review:** tick a box for each item to keep, or, in section 6, name a row and a number. Write a note after an item to change it.

## 1. Text in the current theme

Each line below uses the real Markdown, so it shows the colour the preview gives it now.

- A heading: the `##` titles on this page
- **Bold text**, and *italic text*, and ***both***
- A [link to the palette README](README.md)
- `inline code`, such as `design-check.py`
- <mark>highlighted text</mark>
- [x] a ticked box, and [ ] an empty one

> A quote, with its bar and background.

Every kind of node, drawn by the preview:

```graph
begin start
end done
fail stopped
skill a_skill
hook a_hook
external a_component
start: Where the flow starts
ok?: A decision: is it ok?
a_skill: A skill the flow loads
a_hook: A hook that runs on a write
a_component: Another component, such as a tool
start -> ok?, a_skill
ok? -> step [yes], stopped [no]
step -> done, a_hook, a_component
```
