# Graph colours: designs not chosen

- **Hex values in a colour line.** Not chosen: any colour could then reach a graph, outside what the user kept in the palette.
- **A colour key on the node's own line,** such as `a: text {fill=tan}`. Not chosen: it mixes the colour into the description, and a link has no line of its own to hold it.
- **One `style` line per kind of node,** such as `style external fill=olive`. Not chosen: the user asked to colour one node or one link, and the kinds already have their colours.
- **Firebrick as a fill.** Not chosen: red is for errors only, and the failure node already uses it.
