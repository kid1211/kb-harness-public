# Graph node names: designs not chosen

- **Spaces in a node name.** A name such as `grocery receipt`, with a space. Not chosen: each line form splits on spaces, so this changes each graph. The page shows `_` as a space.
- **An error in place of a warning.** A long name stops the draw, and the page shows the error box. Not chosen: pages stop for a small rule. A warning fails the graph check, and the page still shows the graph.
