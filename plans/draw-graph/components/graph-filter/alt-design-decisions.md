# Graph filter: designs not chosen

- **A row on every graph.** Not chosen: most graphs are small flows, and a row of buttons under each would add noise. A `filter` line turns it on.
- **Tick boxes.** Not chosen: the user asked for buttons in rows. A button that dims when off reads as a toggle.
- **A new layout after each click.** Not chosen for the PoC: the nodes would jump. The shown nodes keep their place, and the graph fits them.

- **A depth toggle, -1, 0 and +1** (F7, F8): showed the nodes one link up or down from the selected ones, and -1 and +1 could be on together. Removed 2026-11-21: the user found it not useful.
