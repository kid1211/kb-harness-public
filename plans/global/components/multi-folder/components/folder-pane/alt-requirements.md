# Folder pane: changed requirements

Changed by the user on 2026-11-20, after a look at the first build:

- Was **F2.** The pane lists each folder the session loads: the start folder and each added folder, under its project. *(the user, 2026-11-20)*
- Was **F3.** The pane splits the folders into one section per role from the map, such as code, KB and tooling. *(the user, 2026-11-20)*
- Was **F4.** At the bottom, the pane lists the supporting docs of each project in the session: its KB folders from the map, with their role. *(the user, 2026-11-20)*
- Was **F1.** A button above the prompt, like the config button of writing-mode, opens and closes a pane on the side. *(the user, 2026-11-20)* Changed 2026-11-20: the two buttons sit side by side in one line, and the folders button has the glyph `⧉`.

Why: the pane must show two main things, the coding folders and the KBs that are loaded. The start folder is known, and supporting docs are the KBs.
